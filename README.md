# PalindromeCheckerApp
Use case 1: Application Entry and Welcome Message

Description :

This is a palindrome checker app

In this app we are going to check whether the given input by the user is a palindrome or not

First lets know what is a palindrome , a palindrome is a word which when read both normally and from backwords will be the same
. For example : DAD if we read it normally it will be DAD and if i read it backwards it will be the same only

This is the use case 1 part of the app
We have successfully printed the welcome message and the version of the app

Our goal is to establish a clear startup flow
